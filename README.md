# ROOTLINE

**The culture, owned by the culture.**

ROOTLINE is a cinematic, Black-owned creator video network concept — a home for the sounds, stories, and storytellers that built the culture, from jazz to trap, gospel to Afrobeats, one unbroken line.

## What it is

A single-page immersive web experience presenting ROOTLINE as a creator-first streaming network:

- **The Lineage** — a scrolling timeline honoring the elders and the innovators on the same stage: the Jazz Age, gospel & the church, soul & funk on the porch, the birth of hip hop at 1520 Sedgwick Ave, the golden era to the blog era, and beyond.
- **The Culture Channels** — curated programming lanes across hip hop, roots, jazz, gospel, and the wider diaspora, with live rooms and a watch experience.
- **The Studio** — a concept creator pipeline: upload, process, publish — built so creators keep their masters, their audience, and their data.
- **The Creator Fund** — ownership-first economics for the people who make the work.

## The receipts model

ROOTLINE's transparency promise: **every decision that touches your money comes with a receipt.** No black boxes, no fine print, no funny math. Creators keep their masters, their audience, and their data — what's yours stays yours; we just give it a stage.

## Tech stack

- **React 19 + TypeScript** on **Vite**
- **Tailwind CSS** + **shadcn/ui** components
- **lucide-react** icons
- Cinematic scroll-driven sections with AI-generated concept art, intro film, and sound design

## Quickstart

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (default `http://localhost:5173`).

Other scripts: `npm run build` (production build to `dist/`), `npm run preview`, `npm run lint`.

## Note on media

All imagery, video, and audio in `public/` is **AI-generated concept art** created for this concept presentation. ROOTLINE is a design concept, not a launched service.
